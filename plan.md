# План разработки проекта py1cv8

тестовый сервер sql - postgres@localhost:5433

## Текущее состояние проекта

Проект **py1cv8** — это MCP-сервер для доступа к метаданным и данным баз 1С:Предприятие 8 напрямую из SQL (PostgreSQL/MSSQL) без использования сервера приложений 1С.

### Что уже реализовано

#### ✅ Архитектура и базовые принципы (Раздел 1 musthave.md)
- **Прямой доступ к БД** — чтение данных через SQLAlchemy ORM
- **Строгий Read-Only** — проверка SELECT/WITH в run_sql
- **Мульти-базовость** — MultiDbProvider, AVAILABLE_DBS
- **Чистая архитектура** — DI через Contracts (contracts/)
- **ORM** — SQLAlchemy 2.0 Mapped аннотации (models.py)
- **Извлечение структуры** — metadata_binary.py, metadata_xml.py
- **Квалификаторы типов** — длина строки, точность числа, формат даты
- **Агностик конфигураций** — универсальные инструменты для любой базы 1С

#### ✅ MCP-сервер (Раздел 2 musthave.md)
- **stdio транспорт** — для локальных процессов
- **SSE транспорт** — Server-Sent Events (legacy HTTP)
- **Streamable HTTP** — рекомендуемый для удаленного доступа
- **Resources** — доступ к JSON-схемам через `1c://{db}/tables/{table}`

#### ✅ Инструменты MCP (Раздел 3 musthave.md)
**Обзор и структура (3.1):**
- `get_db_overview` — полный обзор базы данных
- `get_schema` — структура таблицы или список всех таблиц
- `search_metadata` — поиск объектов по UUID/категории/имени
- `analyze_object` — детальный бизнес-анализ объекта
- `explain_object` — комбинированный анализ (метаданные + связи + данные)
- `get_relationship_map` — граф связей таблицы (outgoing/incoming)

**Запросы и данные (3.2):**
- `run_sql` — выполнение read-only SQL SELECT
- `table_stats` — статистика таблицы (NULL%, distinct, диапазоны)
- `find_by_value` — глобальный поиск значения по всем таблицам
- `orphaned_records` — поиск битых ссылок (RRef/RTRef)

**BSL-код (3.3):**
- `get_bsl_code` — извлечение BSL из ConfigStorage
- `search_bsl_code` — полнотекстовый поиск в BSL-модулях
- `search_1c_queries` — поиск 1С-запросов с переводом в SQL

**Конфигурация и diff (3.4):**
- `get_config_snapshot` — снимок конфигурации из configsave.versions
- `find_changed_objects` — сравнение configsave vs config
- `get_object_config_history` — история версий объекта
- `config_diff_detail` — детальный unified diff объекта

#### ✅ Парсинг метаданных (Раздел 4 musthave.md)
- **DBNames** — чтение и распаковка бинарного блоба из params
- **Config/ConfigCas** — чтение сжатых блобов, извлечение UUID, type_num
- **MOXCEL** — парсинг заголовков блобов
- **XML-выгрузка** — парсинг `.staff/.export_from_1c/`
- **Граф связей** — автоматическое определение RRef/RTRef/Owner/Parent

#### ✅ Трансляция запросов 1С в SQL (Раздел 5 musthave.md)
- Извлечение текстов запросов из BSL (`Запрос.Текст = "..."`)
- Перевод в SQL через SQLAlchemy expression trees
- Поддержка диалектов PostgreSQL и MSSQL
- Трансляция функций работы с датами (Год, Месяц, День, Час)
- Разрешение имен таблиц (Справочник.Контрагенты → `_referenceXX`)
- Обработка параметров запросов (`&Параметр` → `:Параметр`)

#### ✅ Извлечение и декодирование BSL-кода (Раздел 6 musthave.md)
- Декомпрессия блобов (zlib с разными размерами окон)
- Автоматическое определение кодировки (chardet + fallback)
- Разделение блобов на модули по BOM-маркерам
- Очистка кода от служебных заголовков

#### ✅ Сравнение баз данных (Раздел 7 musthave.md)
- Сравнение схем таблиц между несколькими базами
- Сравнение количества строк
- Поиск различий в колонках
- Сравнение высокоуровневых сводок

#### ✅ CLI (Раздел 8 musthave.md)
- `py1cv8 mcp` — запуск MCP-сервера
- `py1cv8 schema --db-url <url>` — вывод сводки по схеме
- Поддержка переменных окружения (`PY1CV8_DB_URL`)

#### ✅ Вспомогательные возможности (Раздел 9 musthave.md)
- **Логирование** — unknown_types.log для нераспознанных типов
- **Кэширование** — SchemaLoader lazy singleton
- **Инкрементальное обновление** — stale_uuids через configVersion
- **Строгая типизация** — Pydantic, SQLAlchemy 2.0 Mapped
- **ORM-модели** — config, configcas, params, information_schema

**Решение:** Удалить `get_notification_analytics` из MCP-сервера.
